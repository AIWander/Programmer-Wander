# UniversalAI Integration

Programmer-Wander supplies local development tools. A separately installed UniversalAI pack may
supply CPC lifecycle and hook-parity procedure. Native host policy remains the enforcement layer.

Use `programmer-getting-started` to install, connect, and verify the executable and live MCP schema.
Use `programmer` for actual file, shell, Git, WSL, HTTP, transformation, and system work. If
`cpc-cloud-lifecycle-dispatcher` is installed, invoke it once at CPC start or resume and apply only the
matching `cpc-hook-*` wrappers around Programmer work.

Before shared mutation, apply ownership and write-integrity procedure. Before commands or external
effects, apply command-safety and consent procedure. After a durable mutation, apply write
verification and confirm the result with Programmer readback, diff, hash, or tests. At closeout,
apply complete coverage, skeptic review, breadcrumb completion, and extraction review once.

Do not duplicate the UniversalAI skills inside this plugin. Do not register `programmer.exe` through
both a plugin and a manual host config unless one registration is disabled. Web and mobile hosts need
an authenticated remote bridge; installing instructions does not make local stdio reachable.

Report source found, installed, enabled/discoverable, invoked, and enforcement proven separately.
Only a trusted blocking runtime path that passes a harmless probe may be called enforcement.
